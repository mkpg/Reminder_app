# Implementations Directory

This directory stores all standalone implementation packages, backend scripts, templates, and integration modules created for the **TN SevaGuard** application.

---

## Index of Implementations

| # | Implementation Name | Status | Description | Folder Link |
|---|---|---|---|---|
| **01** | **Google Sheets Two-Way Sync** | ✅ Active | Real-time sync engine connecting Google Sheets as the live database. Allows fetching dues to show on-screen urgent alerts, and writing new reminders from the website form into the sheet. | [`01_google_sheets_sync/`](./01_google_sheets_sync/) |

---

## How Implementations are Organized
Each implementation has its own folder containing:
1. Ready-to-use scripts or source code.
2. Template or sample files (CSVs, configs, or schemas).
3. Detailed setup and maintenance guides (`.md`).
